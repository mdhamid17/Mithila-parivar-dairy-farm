# Mithila Parivar Dairy Farm — Professional Redesign

A premium, responsive one-page website for Mithila Parivar Dairy Farm, Genaur, Madhubani.

## Highlights
- Premium Mithila-inspired visual identity
- Responsive mobile navigation
- Product cards with direct WhatsApp ordering
- Working enquiry form that prepares a WhatsApp message
- Accessible gallery lightbox and keyboard-friendly controls
- Scroll animations with reduced-motion support
- SEO description and semantic page structure

Open `index.html` to preview. Keep all images, `style.css`, and `script.js` in the same folder.
